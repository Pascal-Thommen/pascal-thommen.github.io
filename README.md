# pascal-thommen.github.io

Personal portfolio and project showcase for **Pascal Thommen** (Wirtschaftsinformatiker / Business Informatics Specialist).

Built with [Hugo](https://gohugo.io/) and [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

Live site: [https://pascal-thommen.github.io/](https://pascal-thommen.github.io/)

## Features

- **Clean-Tech Design:** Minimalist, fast, and responsive layout.
- **Dark / Light Mode:** Automatic system preference detection with manual toggle.
- **Multilingual (i18n):** Native support for German (DE), English (EN), and Spanish (ES).
- **Projects Showcase:** Structured portfolio highlighting key ERP, AI-engineering, and web application repositories (VibeCore-ERP, SARIC, UPA Académico PWA, ImportCalculator).
- **Contact Form:** Integrated contact form with validation (email or WhatsApp) and honeypot spam protection, plus direct LinkedIn channel.
- **Automated CI/CD:** Continuous deployment to GitHub Pages via GitHub Actions.

## Local Development

Prerequisites: Hugo Extended (v0.130+).

```bash
# Clone the repository
git clone https://github.com/Pascal-Thommen/pascal-thommen.github.io.git
cd pascal-thommen.github.io

# Start local server with draft rendering
hugo server -D
```

Open [http://localhost:1313](http://localhost:1313) in your browser.
